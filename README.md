# Knowledge Capture

Bolt-ready export of the Knowledge Capture marketing website.

## Run locally

```bash
npm install
npm run dev
```

Open `http://localhost:3000`.

## Import into Bolt

1. Create a new project in Bolt.
2. Upload this ZIP or drag its contents into the project.
3. Ask Bolt to run `npm install`, then `npm run dev`.

The site is a standard Next.js project. The main page is in `app/page.tsx`, with styling in `app/globals.css`.
